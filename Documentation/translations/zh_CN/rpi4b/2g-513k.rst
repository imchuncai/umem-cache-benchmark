===============
基准测试-2g-513k
===============

结论
====
::

	Umem-cache的命中率比Memcached高13%，比Redis高12%。
	Umem-cache的命中吞吐量比Memcached高16%，比Redis高15%。

	注意：网络吞吐量已经接近千兆网络的极限。
	注意：Redis只用了80%左右的内存。

=========
::

	commit e44dd0b01234bc0faf970e9225e3423e98022129

-------
::

	./autogen.sh
	./configure --enable-tls
	make -j

	taskset -c 1 ./memcached --memory-limit=2048 \
	--max-item-size=1048576 -t 1
