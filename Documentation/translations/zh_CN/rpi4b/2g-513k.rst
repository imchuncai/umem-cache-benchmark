===============
基准测试-2g-513k
===============

结论
====
::

	Umem-cache的命中率比Memcached高12%，比Redis高12%。
	Umem-cache的命中吞吐量比Memcached高10%，比Redis高9%。

	注意：网络吞吐量已经接近千兆网络的极限。
	注意：Redis只用了80%左右的内存。

Memcached
=========
::

	commit f1674f0231e5d291db474c4ad297f5f069d32521

编译命令
-------
::

	./autogen.sh
	./configure --enable-tls
	make -j

运行命令
-------
::

	taskset -c 1,2,3 ./memcached --conn-limit=512 --memory-limit=2048 \
	--max-item-size=1048576 -t 3 -u root
