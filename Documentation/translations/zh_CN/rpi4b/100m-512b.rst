=================
基准测试-100M-512B
=================

结论
====

性能测试结果显示UMEM-CACHE拥有最好的性能表现，比MEMCACHED好19%左右，比REDIS好75%左右。

MEMCACHED
=========
::

	commit 4b9e6198fc44c9eb3ae80802a1b0dcbaf9602969

编译命令
-------
::

	./autogen.sh
	./configure
	make -j

运行命令
-------
::

	./memcached --conn-limit=512 --memory-limit=100 --max-item-size=1048576 -t 4 -u root
