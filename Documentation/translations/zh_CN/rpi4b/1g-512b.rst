===============
基准测试-1g-512b
===============

结论
====
::

	Umem-cache的命中率比Memcached高10%，比Redis高15%。
	Umem-cache的命中吞吐量比Memcached高55%，比Redis高78%。

	Umem-cache的P90  延迟比Memcached低55%，比Redis低54%。
	Umem-cache的P99.9延迟比Memcached低43%，比Redis低50%。

Memcached
=========
::

	commit e44dd0b01234bc0faf970e9225e3423e98022129

-------
::

	./autogen.sh
	./configure --enable-tls
	make -j

运行命令
-------
::

	taskset -c 1 ./memcached --memory-limit=1024 \
	--max-item-size=1048576 -t 1
